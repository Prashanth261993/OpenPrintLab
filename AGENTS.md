# OpenPrintLab assistant instructions

Build useful, understandable models; never imply that generated means printable.

- Read `docs/decisions.md`, `models/catalog.json` and the relevant recipe first.
- Use `.github/skills/create-printable-model/SKILL.md` for authoring/customization.
- Lengths are mm. Validate all parameters, including finite values, counts and
  relationships. Do not bypass the limits with scale transforms.
- Core tools: `python -m tools.cli list`, `parameters MODEL`, `check MODEL`,
  `build MODEL --set name=value --output build/variant`.
- Keep generated files in `build/` for one-off variants. Change defaults only
  when requested. Default exports are regenerated by `python -m tools.release`.
- Test with `python -m unittest discover -s tests -v`, then
  `python -m tools.release --check` and `python -m tools.site`.
- For UI changes run the browser checks documented in README.
- Never connect to a printer, send G-code, or supply machine-ready G-code.
- Initial printer is Bambu Lab **P2S**, not P1S. Do not assume AMS ownership.
- Never invent slice times, filament usage, successful prints, photos or evidence.
  Reports explicitly keep slicer_checked and physical_print_tested false.
- Keep suggestions separate from verified facts. Users select actual
  printer/nozzle/plate/filament presets and inspect their own slices.
- Reject food-contact, electrical, medical, weapon, structural/load-bearing,
  high-temperature and safety-critical designs in this starter collection.
- Reuse shared catalog/build tools across CLI, site and MCP.
- `models/`, including Python design recipes, and `docs/` are CC BY 4.0.
  `tools/`, tests, website code and assistant integrations are MIT.
- Do not add dependencies unless a required capability justifies them.
