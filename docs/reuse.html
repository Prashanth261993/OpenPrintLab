Try it from a full clone

Use Python 3.11+ from the repository root. No CadQuery is needed for inspection; generating CAD templates remains optional. A starter model's minimal source ZIP is not the full toolkit.

python -m tools.cli patterns
python -m tools.cli pattern fastener-selection
python -m tools.cli inspect-stl models\exports\pocket-tray.stl
python -m tools.cli customize pocket-tray --variant review-tray
python -m tools.cli inspect-variant review-tray

Choose an unused variant name. Inspection only reads the model; it does not repair, reorient, overwrite or promote its passport. The report binds the exact STL and checker hashes. The CLI returns 0 for no error findings (warnings may remain), 1 for reported geometry/placement errors, and 2 for invalid input or an unavailable file.

What the report can tell you

Mode or checkMeaning and limit
--mode part (default)Requires one edge-connected component. Checks each component's edge winding/closure, positive volume, Z=0, P2S envelope and requested XY margin.
--mode plateAllows several components but checks each one's placement. One grounded object cannot conceal another floating object.
--mode assemblySkips print placement rules; the assembly is not a printable part. Does not skip basic edge/volume findings.
--margin 5Reserves the user-requested XY edge distance in millimeters, without moving parts. Default is zero, not a practical brim allowance or certified usable-plate mask.
--overhang 45Reports oriented downward-face area exceeding the angle from vertical, excluding triangles at the bed. The default 45 degrees is a review threshold, not a universal printing limit. It does not distinguish bridges from unsupported spans.
--clearance 1Compares edge-connected components' axis-aligned bounding boxes. Separated bounds give a conservative distance lower bound. Overlap, contact or insufficient separation means an exact CAD check is needed, not that collision is proved.

Input is binary STL in millimeters, limited to 200,000 triangles and 128 edge-connected components. Exact shared edges determine connectivity: vertex-only contact is not one component. ASCII STL, general solid repair, vertex-manifold proof, self-intersections, exact collision/clearance, motion envelopes and first-layer islands are not implemented. Enclosed cavity shells can trigger component/negative-volume findings even in a valid solid; review shell nesting in native CAD rather than repairing automatically. Bed-contact area is not a first-layer slice. Interpret topology errors before area/volume metrics, and inspect actual slicing separately.

For custom CAD, export each printable part in its specified print orientation and keep assembly poses separate. Do not silently rescale or alter a model to pass. inspect-stl accepts a local file only in the CLI; MCP accepts only named variants already under this clone's build/variants, rejecting path escapes, symlinks and mismatched STL/report hashes.

Use with your assistant

Restart an existing MCP server after updating the clone; keep normal client permission controls. A successful MCP exchange is not a successful geometry check: inspect has_errors and every finding.

What is not shipped

Bambu P2S project-3MF writing, installable cross-client packages, general new-design automation, exact assembly checking and an evaluation runner remain deferred. Bambu Studio is available on the development machine, but no project package or round-trip/slice verification is claimed by this release. ZIP/schema checks alone would not satisfy that gate.

The adopt/adapt/defer ledger records the reviewed implementations and reasons. Nothing launches design comparisons, installs global instructions or controls a printer.
